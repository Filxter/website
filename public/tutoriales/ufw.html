🚫 Firewall UFW

¿Qué es UFW?

UFW (Uncomplicated Firewall) es una herramienta sencilla para gestionar reglas de firewall en sistemas Linux, especialmente Ubuntu. Su propósito es facilitar la administración de iptables.

Instalación

sudo apt update
sudo apt install ufw

Habilitar UFW

sudo ufw enable

Para comprobar el estado:

sudo ufw status

Permitir conexiones comunes

sudo ufw allow ssh
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

Bloquear conexiones

sudo ufw deny 23

Esto bloquea Telnet.
