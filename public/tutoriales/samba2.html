¿Qué es Samba?

Samba es una herramienta que permite compartir carpetas y archivos entre sistemas Linux y Windows en una red local.

Instalación de Samba

sudo apt update
sudo apt install samba

Crear una Carpeta Compartida

sudo mkdir -p /srv/compartido
sudo chown nobody:nogroup /srv/compartido
sudo chmod 0775 /srv/compartido

Editar el archivo de configuración

sudo nano /etc/samba/smb.conf

Agrega al final del archivo:

[Compartido]
  path = /srv/compartido
  browseable = yes
  read only = no
  guest ok = yes

Reiniciar el servicio

sudo systemctl restart smbd

Ahora puedes acceder desde otro equipo usando la dirección IP: \\IP-del-servidor\Compartido

Creación de Usuarios Samba

sudo useradd recursos
sudo smbpasswd -a recursos

Esto crea un usuario del sistema y lo habilita en Samba.

Compartición con autenticación

En /etc/samba/smb.conf, define:

[Privado]
  path = /srv/privado
  valid users = recursos
  read only = no
  guest ok = no

Crear y proteger carpeta

sudo mkdir -p /srv/privado
sudo chown recursos:recursos /srv/privado
sudo chmod 0700 /srv/privado

Montaje automático en clientes Linux

Agrega en /etc/fstab:

//192.168.1.10/Privado /mnt/privado cifs credentials=/home/usuario/.smbcred,iocharset=utf8,uid=1000,gid=1000 0 0

Archivo de credenciales:

usuario=recursos
contraseña=tu_contraseña

Consejos de seguridad

  • Desactiva guest ok para carpetas privadas.
  • Utiliza firewalls para restringir acceso a puertos Samba (137-139, 445).
  • Habilita auditoría de accesos con herramientas como auditd.
