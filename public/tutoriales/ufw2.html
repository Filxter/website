¿Qué es UFW?

UFW (Uncomplicated Firewall) es una herramienta sencilla para gestionar reglas de firewall en sistemas Linux, especialmente Ubuntu. Su propósito es facilitar la administración de iptables.

Instalación

sudo apt update
sudo apt install ufw

Habilitar UFW

sudo ufw enable

Para comprobar el estado:

sudo ufw status

Permitir conexiones comunes

sudo ufw allow ssh
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

Bloquear conexiones

sudo ufw deny 23

Esto bloquea Telnet.

Política por defecto

Para rechazar todo tráfico entrante y permitir el saliente:

sudo ufw default deny incoming
sudo ufw default allow outgoing

Permitir puertos específicos por IP

Permitir SSH solo desde una IP específica:

sudo ufw allow from 192.168.1.10 to any port 22

Bloquear rangos de IP

Bloquear una red completa:

sudo ufw deny from 203.0.113.0/24

Reglas por interfaz de red

sudo ufw allow in on eth0 to any port 80

Permite tráfico web solo por interfaz eth0.

Eliminar reglas específicas

sudo ufw status numbered
sudo ufw delete [número]

Registro de eventos (logging)

sudo ufw logging on

Los registros aparecen en /var/log/ufw.log.

Consejos de seguridad

  • Desactiva UFW antes de aplicar muchos cambios: sudo ufw disable
  • Revisa regularmente las reglas activas.
  • Evita permitir tráfico desde cualquier origen si no es necesario.
