📡 Compartir Recursos con Samba

¿Qué es Samba?

Samba es una herramienta que permite compartir carpetas y archivos entre sistemas Linux y Windows en una red local.

Instalación de Samba

sudo apt update
sudo apt install samba

Crear una Carpeta Compartida

sudo mkdir -p /srv/compartido
sudo chown nobody:nogroup /srv/compartido
sudo chmod 0775 /srv/compartido

Editar el archivo de configuración

sudo nano /etc/samba/smb.conf

Agrega al final del archivo:

[Compartido]
  path = /srv/compartido
  browseable = yes
  read only = no
  guest ok = yes

Reiniciar el servicio

sudo systemctl restart smbd

Ahora puedes acceder desde otro equipo usando la dirección IP: \\IP-del-servidor\Compartido
